# Release and Signing Guide

[中文](RELEASING.zh-CN.md)

This policy follows common open-source practice: reproducible version metadata, reviewed
release commits, signed Git tags, checksummed archives and detached signatures.

## Maintainer prerequisites

- A hardware-backed OpenPGP signing key is preferred; protect an offline primary key and
  use a time-limited signing subkey.
- Publish the public key/fingerprint in the hosting account and project release notes.
- Require reviewed pull requests and passing release gates on the protected default branch.

## Prepare a release

1. Move relevant `Unreleased` entries in `CHANGELOG.md` to `X.Y.Z` with the release date.
2. Write exactly `X.Y.Z` to `VERSION`; update documentation if compatibility changed.
3. Run `make release-check` in the canonical Ubuntu environment.
4. Review `git diff`, commit with DCO sign-off, and obtain project review.
5. Create an annotated signed tag:

```sh
git tag -s vX.Y.Z -m 'myVMP X.Y.Z'
git tag -v vX.Y.Z
```

6. Build the package from the signed tag in a clean checkout:

```sh
make package
version="$(cat VERSION)"
git archive --format=tar.gz --prefix="myvmp-${version}/" \
  -o "build/dist/myvmp-${version}-source.tar.gz" HEAD
cd build/dist
sha256sum myvmp-X.Y.Z-linux-*-tool.tar.gz myvmp-X.Y.Z-source.tar.gz > SHA256SUMS
gpg --armor --detach-sign SHA256SUMS
gpg --verify SHA256SUMS.asc SHA256SUMS
```

7. Upload the binary archive, corresponding source archive, `SHA256SUMS`,
   `SHA256SUMS.asc`, release notes and signing-key fingerprint to the hosting platform's
   release for the same tag. Keeping exact corresponding source beside every GPL binary
   is part of the release policy.
8. Verify the downloaded artifacts on a second machine before announcing the release.

Do not sign mutable branch archives generated by a hosting UI. Sign the project-built
versioned archive and checksum manifest. If the project later adopts Sigstore, publish a
documented identity/issuer policy and keep OpenPGP verification during migration.

## User verification

```sh
gpg --import myvmp-release-key.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum -c SHA256SUMS
tar -xzf myvmp-X.Y.Z-linux-x86_64-tool.tar.gz
./myvmp-X.Y.Z/myvmp --version
```

The printed version must match the signed tag and archive directory.
